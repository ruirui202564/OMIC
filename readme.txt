This is the code repository for "Online Learning from Multi-class Imbalanced Capricious Data Streams" (OMIC).

Run main_OMIC.py, the corresponding results can be obtained.

Note:
Due to the file size limit, other datasets can be downloaded from the website:
- 'creditcard', 'census', 'hepatitis': https://drive.google.com/file/d/1N90LJdFVK_Fy-Z3a45nY26PAiOZTQBsQ/view?pli=1. The original datasets are in .arff, and they should be transformed into .xlsx first.
- 'covtype', 'lymph', 'zoo': https://drive.google.com/file/d/19F7krux2PnhFJzM7lOwNOLT26NHnZXbo/view. The original datasets are in .arff, and they should be transformed into .xlsx first.
- The synthetic datasets should first be generated use the corresponding codes.
